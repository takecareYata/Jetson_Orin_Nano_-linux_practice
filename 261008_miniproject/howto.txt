1. 디바이스 트리에 노드 추가

	my_pdev@2212880 {
		compatible = "my-pdev";
		reg = <0x0 0x02212880 0x0 0x20>;
		interrupt-parent = <0xf3>;
		interrupts = <133 3>;
	}; 

2. 실행 방법
sudo mknod /dev/mydev c 120 0
sudo rmmod devtest
sudo insmod devtest.ko
sudo ./apptest D
