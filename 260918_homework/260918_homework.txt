- 과제 1
`cmd` 또는 $(cmd) 로 표현되는 명령 치환에 대해 조사하시오

쉘 스크립트에서 명령어의 실행 결과(표준 출력, stdout)를 문자열 값으로 변환하여 변수에 저장하거나 
다른 명령어의 인자로 전달하는 기능
명령 치환 과정에서 결과 문자열 끝에 붙어 있는 모든 개행 문자는 자동으로 삭제됨.
명령어 실행 중 발생하는 에러 메시지(stderr)는 변수에 담기지 않고 화면에 출력됨. 
에러 메시지까지 함께 저장하려면 $(cmd 2>&1) 형태의 리다이렉션을 함께 사용해야함.

` : Backtick : 중첩구문을 만들 때, \로 이스케이프해야함. 
$ : 중첩구문을 만들 때, 자연스럽게 중첩이 가능함.
예시 1: 

# 현재 날짜 저장
TODAY=$(date +%Y-%m-%d)
echo "Today is $TODAY"

# 구식 표현 (동일하게 동작)
TODAY=`date +%Y-%m-%d`

예시 2: 중첩구문

# 백틱 구문 (가독성이 떨어지고 작성하기 어려움)
path_files=`ls \`pwd\``

# $(cmd) 구문 (직관적이고 깔끔함)
path_files=$(ls$(pwd))
